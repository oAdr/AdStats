AdStats

Owner-operated QQ bot for read-only Hypixel player statistics.

Project

AdStats accepts an authorized user's Minecraft username through QQ and returns a generated statistics image. The production service runs on an operator-controlled Windows server. It is not a Minecraft client, mod, or gameplay automation tool.

Public reference version

This project includes a small Python reference client and a machine-readable version declaration. The reference client demonstrates the read-only Hypixel request path without the production QQ gateway, administrator controls, credentials, or persistent storage.

Hypixel API use

For each accepted lookup, the reference client resolves the Minecraft UUID and makes one read-only request to GET https://api.hypixel.net/v2/player?uuid=<UUID> with an API-Key request header. The response is used in memory for aggregate rank and BedWars, SkyWars, Duels, and related player statistics. No Hypixel write endpoint is used.

Privacy and caching

The public reference client writes no files, databases, caches, telemetry, or logs. Requests use Cache-Control: no-cache, no-store. The process prints a limited summary and exits; in-memory data is discarded. The production bot deletes its temporary reply image after upload and keeps operational access-control metadata separately on the operator's server.

Key security

The reference client reads HYPIXEL_API_KEY from the process environment. The key is never placed in a URL, printed, logged, or included in this repository. The production server stores its key encrypted and does not distribute it to QQ users, clients, or mods.

Traffic controls

The production bot has a pending lookup queue capacity of three and serializes renderer execution. It can enforce an administrator-controlled per-user cooldown from 1 to 3600 seconds. The public reference client performs one request per invocation and does not retry or cache a response.
